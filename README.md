This is the in-development version of a LISP-like language for encumbering and releasing funds with smart-contract capabilities.

See docs/clvk.org or https://chiklisp.com/ for more info.


Testing
=======

    $ python3 -m venv venv
    $ . ./venv/bin/activate
    $ pip install -e '.[dev]'
    $ pytest tests
